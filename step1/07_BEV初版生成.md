# 环节七：BEV 初版生成

## 1. 环节定位

BEV 鸟瞰图是感知结果的统一表达形式之一，也是后续规划控制最容易使用的环境表示。任务要求构建无人船周围 10 m 范围内的鸟瞰图，并发布到指定话题。因此 BEV 应在第一阶段尽早实现，即使初版只是简单占据图。

BEV 的作用包括：

1. 可视化船体周围障碍物分布。
2. 检查点云滤波和聚类效果。
3. 表达近距离障碍物占据关系。
4. 为后续规划避障提供栅格地图。
5. 为比赛 BEV 误差评估提供输出。

## 2. 输入数据

BEV 初版主要输入：

```text
base_link 坐标系下的点云
LiDAR cluster 中心
船体简化模型
目标分类结果
```

第一版可只使用 LiDAR 点云，不依赖相机。

## 3. BEV 范围与分辨率

推荐设置：

```text
范围：x ∈ [-10, 10] m
范围：y ∈ [-10, 10] m
分辨率：0.05 m 或 0.1 m
图像尺寸：400×400 或 200×200
```

若使用 0.1 m 分辨率，则 20 m × 20 m 范围对应 200×200 图像。若使用 0.05 m 分辨率，则对应 400×400 图像。

## 4. 栅格定义

初版占据图可采用灰度值：

```text
0：空闲区域
128：未知区域
255：障碍物区域
```

也可以单独标记船体区域：

```text
200：船体自身区域
```

后续可扩展为语义 BEV：

```text
浮球
立柱
游动船只
浮块
未知障碍
船体遮罩
```

## 5. 任务要求

本环节需要完成：

1. 将点云转换到 base_link 坐标系。
2. 只保留 10 m 范围内点云。
3. 将点云投影到 x-y 平面。
4. 根据分辨率映射到栅格坐标。
5. 设置船体遮罩区域。
6. 根据障碍物点或 cluster 填充占据栅格。
7. 输出 BEV 图像。
8. 在图像中标记船体、坐标轴、目标中心。

## 6. 坐标映射

对于 base_link 下的点：

```text
x, y
```

映射到 BEV 像素：

```text
u = int((y - y_min) / resolution)
v = int((x_max - x) / resolution)
```

注意图像坐标系 v 轴向下，而船体系 x 轴向前，因此通常需要翻转 x 方向。

## 7. 输出格式

建议同时支持：

```text
bev_debug.png                  # 调试图
sensor_msgs/msg/Image          # ROS2 发布格式
numpy array                    # 算法内部格式
```

如果赛事模板对 `/world/obstacles/bev_check` 消息类型有明确要求，应以模板为准。

## 8. 验收标准

本环节完成后，应满足：

- 能生成船体周围 10 m 的 BEV 图。
- 船体位置位于 BEV 中心。
- 前方、左侧、右侧方向与实际坐标一致。
- 障碍物点能正确落在 BEV 对应位置。
- 船体自身区域不会被误认为外部障碍物。
- BEV 图可用于人工检查点云处理结果。

## 9. 风险与应对

| 风险 | 应对方法 |
|---|---|
| BEV 前后左右方向错误 | 在图中标注 x/y 坐标轴，通过已知目标验证 |
| 分辨率过低导致目标模糊 | 使用 0.05 m 分辨率测试 |
| 分辨率过高导致计算慢 | 第一版用 0.1 m，后续优化 |
| 船体遮罩覆盖目标 | 调整遮罩范围，并保留近距离原始点用于调试 |
| 点云未转换到 base_link | 第一版可单传感器 BEV，融合前必须统一坐标 |
