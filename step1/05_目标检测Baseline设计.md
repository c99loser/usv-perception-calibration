# 环节五：目标检测 Baseline 设计

## 1. 环节定位

目标检测是感知任务的直接输出基础。比赛要求识别无人船周围的浮球、游动船只、立柱、浮块，并以船中心为原点发布相对位置。第一阶段目标检测不应一开始追求深度学习最优效果，而应先建立 LiDAR 几何检测和 Camera 图像检测的 baseline。

Baseline 的作用是：

1. 快速验证数据链路和坐标关系。
2. 为后续深度学习模型提供对照结果。
3. 为多传感器自标定提供自然目标中心。
4. 为评估脚本和结果发布接口提供输入。

## 2. 检测输入

本环节的输入包括：

```text
LiDAR 聚类结果
Camera 图像候选框
船体坐标系 base_link
传感器初始外参
```

其中 LiDAR 用于定位，Camera 用于辅助分类。

## 3. LiDAR 几何检测 Baseline

### 3.1 输入

来自点云聚类模块的 cluster 特征：

```text
center_x, center_y, center_z
bbox_length, bbox_width, bbox_height
num_points
aspect_ratio
z_min, z_max
```

### 3.2 分类规则

| 目标 | 判据建议 |
|---|---|
| 浮球 | 包围盒小、点数少、宽高接近、距离较近 |
| 立柱 | 高度大于宽度，竖直方向点分布明显，位置稳定 |
| 游动船只 | 包围盒较大，长宽比明显，多帧位置变化 |
| 浮块 | 尺寸接近 2 m × 2 m，低矮，高度较小 |
| 未知障碍 | 不满足明确规则但具有实体 cluster |

第一版可以将所有 cluster 输出为 unknown，再逐步加入规则分类。

### 3.3 输出

每个目标输出：

```text
class_name
center_in_base_link
bbox_size
confidence
source_lidar
timestamp
```

## 4. Camera 图像检测 Baseline

### 4.1 传统图像处理方法

第一版可用：

```text
HSV 阈值
轮廓提取
面积筛选
长宽比筛选
圆形度筛选
```

适合先检测颜色明显的浮球和形状明显的立柱。

### 4.2 深度学习方法预留

后续可接入：

```text
YOLOv8
YOLOv11
RT-DETR
Mask R-CNN
```

当前训练主输入为六路原始 `image_raw`。建议用官方仿真真值离线生成训练标签，
并以原始 MCAP 的少量人工标注作为独立验证/微调集。真值不得进入运行节点。
矫正图只在映射已独立验证且部署端使用同一映射时作为辅助训练域，不作为唯一
训练输入。

### 4.3 图像检测输出

```text
class_name
bbox_2d
confidence
camera_name
timestamp
pixel_center
bearing_angle
```

其中 bearing_angle 可用于和 LiDAR cluster 进行方向匹配。

## 5. LiDAR 与 Camera 的功能分工

| 传感器 | 优势 | 在 Baseline 中的作用 |
|---|---|---|
| LiDAR | 空间定位准确 | 输出目标中心、尺寸、距离 |
| Camera | 颜色和语义信息丰富 | 辅助判断目标类别 |
| LiDAR + Camera | 互补 | 提高分类稳定性和漏检修正能力 |

第一阶段应以 LiDAR 定位为主，相机分类为辅。

## 6. 检测结果筛选

为减少误检，应加入以下规则：

1. 距离过近且在船体遮罩附近的目标剔除。
2. 点数过少且无法连续出现的目标剔除。
3. 图像检测置信度过低的候选框剔除。
4. 多帧中位置跳变过大的目标降低置信度。
5. 与任何 LiDAR cluster 无法对应的图像目标暂不输出三维位置。

## 7. 验收标准

本环节完成后，应满足：

- 能从 LiDAR cluster 中生成目标候选。
- 能从图像中生成目标候选框。
- 能对浮球、立柱、游船、浮块进行初步分类。
- 能将目标中心转换到 base_link 坐标系。
- 能输出调试用目标列表。
- 能在图像和 BEV 中显示检测结果。

## 8. 风险与应对

| 风险 | 应对方法 |
|---|---|
| LiDAR 几何规则分类不稳定 | 先输出 unknown，再引入多帧跟踪和相机语义 |
| 浮球点云太稀疏 | 降低聚类点数阈值，结合相机检测 |
| 游船与浮块尺寸相近 | 加入多帧速度判断 |
| 图像颜色阈值受光照影响 | 使用 HSV + LAB 多颜色空间和图像增强 |
| 深度学习数据不足 | 用 USVSim 真值自动生成训练集 |
