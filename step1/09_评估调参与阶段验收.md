# 环节九：评估、调参与阶段验收

## 1. 环节定位

评估和调参用于判断第一阶段的数据处理功能是否有效。比赛评价指标包括 BEV 精度、障碍物检测精度、检测遗漏率、激光融合精度等。因此第一阶段不能只看“程序是否运行”，还需要建立可量化的误差分析工具。

如果 MCAP 中包含真值话题，可以直接用于离线评估。如果没有真值话题，则应人工标注少量帧作为验证集。

## 2. 评估输入

评估模块输入包括：

```text
算法输出 PoseArray
算法输出 BEV
算法输出融合点云
真值 PoseArray 或人工标注结果
原始图像和点云
```

真值话题只能用于评估和训练，不能作为正式算法输入。

## 3. 主要评估指标

### 3.1 目标中心误差

对每一类目标，计算检测中心与真值中心之间的距离：

```text
error = sqrt((x_pred - x_gt)^2 + (y_pred - y_gt)^2)
```

可分别统计：

```text
平均误差
中位数误差
最大误差
不同距离段误差
```

### 3.2 漏检率

```text
漏检率 = 未匹配真值目标数 / 真值目标总数
```

应按类别分别统计：

```text
浮球漏检率
游船漏检率
立柱漏检率
浮块漏检率
```

### 3.3 误检率

```text
误检率 = 未匹配预测目标数 / 预测目标总数
```

误检率可帮助调整聚类阈值、图像检测阈值和船体遮罩范围。

### 3.4 BEV 误差

若有俯视图或真值投影，可以比较：

```text
占据栅格 IoU
障碍物区域像素误差
目标中心在 BEV 中的偏差
```

第一阶段可先做人工可视化检查，后续再做自动量化。

### 3.5 点云融合质量

多 LiDAR 融合前期可检查：

```text
同一目标是否出现重影
点云是否存在明显错位
不同 LiDAR 的障碍物中心是否接近
```

后续可用 ICP/GICP 残差或目标中心一致性误差量化。

## 4. 匹配策略

预测目标与真值目标匹配可采用：

```text
最近邻匹配
匈牙利匹配
距离阈值过滤
按类别匹配
```

建议第一版距离阈值：

```text
浮球：1.0 m
立柱：1.0 m
浮块：1.5 m
游船：2.0 m
```

后续根据数据实际误差调整。

## 5. 调参对象

需要重点调参的内容包括：

```text
点云 ROI 范围
高度裁剪范围
体素下采样大小
离群点滤波参数
DBSCAN eps 和 min_samples
船体遮罩范围
图像颜色阈值
检测置信度阈值
LiDAR-Camera 匹配角度阈值
BEV 分辨率
```

## 6. 阶段性验收标准

第一阶段验收建议分为三档。

### 6.1 基础通过

- 所有数据可读取。
- 所有要求话题可发布。
- 点云和图像可视化正常。
- BEV 能显示基本障碍物分布。

### 6.2 功能可用

- LiDAR 能稳定聚类出主要障碍物。
- 图像能框出部分目标候选。
- PoseArray 坐标方向正确。
- 检测结果与真值位置大致一致。

### 6.3 可进入下一阶段

- 主要障碍物漏检率可接受。
- 船体自身点基本剔除。
- BEV 中障碍物位置稳定。
- LiDAR-Camera 投影关系基本正确。
- 评估脚本能自动输出误差表。

## 7. 建议输出文件

```text
evaluation_report.md
error_by_class.csv
miss_rate_by_class.csv
bev_debug_examples/
projection_debug_examples/
parameter_record.yaml
```

每次调参后应记录参数版本，避免结果无法复现。

## 8. 风险与应对

| 风险 | 应对方法 |
|---|---|
| 真值话题缺失 | 人工标注少量帧作为验证集 |
| 检测和真值时间不同步 | 使用时间戳近邻匹配 |
| 类别误判影响误差统计 | 先做不分类障碍物评估，再做分类评估 |
| 调参无记录 | 每次实验保存参数文件和评估结果 |
| 只看可视化缺少量化 | 建立 CSV 误差表和自动统计脚本 |
