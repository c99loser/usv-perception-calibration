# 环节四：鱼眼相机图像处理与矫正

## 1. 环节定位

鱼眼相机提供大视场图像，有利于识别浮球、船只、立柱和浮块等目标的颜色、轮廓和语义类别。但鱼眼图像存在显著畸变，目标在图像边缘会被拉伸，直接使用普通相机检测模型效果可能较差。

本环节的目标不是简单地把所有鱼眼图像恢复为普通透视图，而是建立鱼眼图像的读取、显示、矫正、增强和目标候选检测基础能力。当前已经选择“原始图像作为主训练与检测输入、矫正图作为辅助域和几何检查输入”，详见项目根目录 `当前进行路线.md`。

## 2. 输入数据

输入为 6 路鱼眼相机图像，一般包括：

```text
front_camera
back_camera
left_camera
left2_camera
right_camera
right2_camera
```

图像通常为 1280×720，水平视场约 175°。相机与对应 Airy LiDAR 的安装姿态绑定，高度相差约 0.1 m。

## 3. 处理流程

推荐流程如下：

```text
ROS Image 读取
→ OpenCV 图像转换
→ 图像基础检查
→ 相机内参和畸变参数获取
→ 鱼眼矫正或近似展开
→ 图像增强
→ 目标候选检测
→ 可视化保存
```

## 4. 任务要求

### 4.1 图像读取

需要将 `sensor_msgs/msg/Image` 转换为 OpenCV 可处理的图像格式：

```text
BGR / RGB / grayscale
```

需要检查：

- 分辨率是否正确。
- 图像是否上下或左右翻转。
- 六路相机方向是否与名称一致。
- 图像是否存在压缩格式，需要解码。

### 4.2 内参来源判断

内参获取优先级如下：

```text
1. MCAP 中的 CameraInfo
2. YAML 文件中的 camera_matrix 和 distortion_coefficients
3. 根据图像分辨率和 FOV 估算初始内参
```

如果只有 FOV，可先估计焦距：

```text
fx ≈ image_width / (2 * tan(HFOV / 2))
fy ≈ fx
cx ≈ image_width / 2
cy ≈ image_height / 2
```

但鱼眼相机更适合使用 OpenCV fisheye 模型或等距投影模型。

### 4.3 鱼眼矫正策略

当前生效策略以项目根目录 `当前进行路线.md` 为准：目标检测模型使用原始
`image_raw` 作为主训练域和部署输入。建议保留两条图像流：

```text
原始鱼眼图像：主训练域和正式检测输入
矫正图像：用于可视化、几何投影、人工检查和辅助域消融
```

不建议只保留矫正图像，因为鱼眼矫正可能带来：

- 边缘视场丢失。
- 图像边缘拉伸。
- 插值误差。
- 小目标形状失真。

只有在内参/畸变参数独立验证、映射版本固定、训练与部署采用完全相同映射时，
矫正图才可作为辅助训练域。基于 FOV 估算回退模型生成的图像不得作为训练
标注母版或几何真值。

### 4.4 图像增强

水面场景可能存在反光、低对比度、小目标和阴影。建议尝试：

```text
CLAHE 对比度增强
Gamma 校正
HSV 颜色空间增强
锐化或边缘增强
去雾/亮度归一化
```

图像增强应作为可配置模块，不应固定死在检测流程中。

### 4.5 图像目标候选检测

第一版可先采用传统方法：

```text
HSV 阈值分割
轮廓提取
面积筛选
长宽比筛选
圆形度筛选
```

后续可替换为 YOLOv8、YOLOv11 或其他检测模型。

## 5. 目标类型分析

| 目标 | 图像特征 |
|---|---|
| 浮球 | 颜色明显，通常为小尺寸圆形或椭圆区域 |
| 游动船只 | 轮廓较大，长条形，可能有白色、灰色或深色结构 |
| 立柱 | 竖直细长，边缘明显，颜色可能较暗 |
| 浮块 | 低矮矩形，形状较规则，但远距离可能不明显 |

相机更适合提供类别信息，LiDAR 更适合提供距离和位置。

## 6. 建议输出

```text
raw_frame_front.png              # 原始鱼眼图像
undistorted_front.png            # 矫正图像
detection_debug_front.png        # 目标候选框图像
camera_intrinsics.yaml           # 相机内参整理结果
fisheye_maps/                    # remap 查表文件
```

## 7. 验收标准

本环节完成后，应满足：

- 能显示六路鱼眼图像。
- 能保存原始图像帧。
- 能根据内参或近似模型生成矫正图。
- 能在图像中提取部分浮球、船只、立柱或浮块候选框。
- 能保留原始图像和矫正图两条处理路径。
- 能为后续 LiDAR-Camera 投影提供相机模型。

## 8. 风险与应对

| 风险 | 应对方法 |
|---|---|
| 没有准确内参 | 先用 FOV 估计初值，后续通过标定优化修正 |
| 矫正后边缘目标变形严重 | 保留原始鱼眼图像检测分支 |
| 水面反光影响颜色阈值 | 加入图像增强和多颜色空间判断 |
| 传统检测漏检较多 | 后续使用 YOLO 并用仿真数据微调 |
| 不同相机方向混淆 | 用可视化和已知目标方向逐一确认 |
