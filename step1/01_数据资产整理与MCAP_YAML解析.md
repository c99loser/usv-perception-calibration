# 环节一：数据资产整理与 MCAP / YAML 解析

## 1. 环节定位

数据资产整理是整个感知系统开发的第一步。当前已知数据来源包括赛事 PDF、YAML 配置文件、MCAP 录制数据，以及文本形式的船体尺寸信息。由于船体没有实体 ROS2 可读模型，YAML 和 MCAP 就成为后续建立传感器输入、坐标关系和算法参数的主要依据。

该环节的目标是弄清楚“我们到底有哪些数据、数据格式是什么、频率是多少、能不能读取、哪些数据只能用于评估”。如果这一环节没有完成，后续点云处理、图像处理、目标检测和融合都会缺少稳定输入。

## 2. 输入数据

本环节主要处理以下输入：

| 数据类型 | 作用 |
|---|---|
| PDF 文档 | 理解任务要求、传感器数量、话题命名、评价指标 |
| YAML 文件 | 读取传感器配置、话题名称、可能的内参和外参初值 |
| MCAP 文件 | 离线读取赛事方录制的 LiDAR、Camera、可能的真值数据 |
| 船体文本信息 | 提取船体尺寸，用于建立 base_link 和船体遮罩 |

## 3. 任务要求

本环节需要完成以下任务：

1. 列出 MCAP 中所有 topic。
2. 统计每个 topic 的消息类型、发布频率、起止时间。
3. 区分传感器数据话题和评估真值话题。
4. 确认 7 路 LiDAR 点云话题是否完整。
5. 确认 6 路鱼眼相机图像话题是否完整。
6. 检查是否存在 CameraInfo 话题。
7. 检查是否存在 `/world/obstacles/*` 真值话题。
8. 解析 YAML 中的相机内参、畸变参数、LiDAR 参数和外参初值。
9. 将整理结果写成数据说明表。

## 4. 建议输出文件

建议生成以下中间文件：

```text
data_summary.md            # 数据说明文档
topic_list.csv             # topic 名称、类型、频率、样本数
sensor_topics.yaml         # 整理后的传感器话题配置
mcap_time_range.txt        # MCAP 起止时间与时长
```

## 5. 推荐检查内容

### 5.1 LiDAR 数据检查

需要确认：

- 是否为 `sensor_msgs/msg/PointCloud2`。
- 是否包含 x、y、z 字段。
- 是否包含 intensity、ring、time 等额外字段。
- 点云坐标单位是否为 m。
- 每一路点云的频率是否接近任务说明中的 10 Hz。
- 是否存在明显空帧或异常帧。

### 5.2 Camera 数据检查

需要确认：

- 是否为 `sensor_msgs/msg/Image`。
- 分辨率是否为 1280×720。
- 编码格式是 RGB、BGR、mono8 还是 compressed。
- 是否存在对应的 CameraInfo。
- 六路相机方向是否符合 front、back、left、left2、right、right2。

### 5.3 真值数据检查

如果 MCAP 中包含真值话题，需要单独标记。真值话题可以用于：

- 训练数据自动标注。
- 调试检测误差。
- 离线评估漏检率。

但不能用于正式感知算法输入。

## 6. 代码建议

建议优先编写以下脚本：

```text
mcap_info.py              # 打印 MCAP 基本信息
extract_images.py         # 从 MCAP 导出图像帧
extract_pointclouds.py    # 从 MCAP 导出点云帧
parse_yaml_config.py      # 解析 YAML 配置
sync_preview.py           # 按时间戳同步预览图像和点云
```

## 7. 验收标准

该环节完成后，应能回答以下问题：

1. MCAP 中一共有多少个 topic？
2. 哪些 topic 是 LiDAR 点云？
3. 哪些 topic 是鱼眼相机图像？
4. 每个 topic 的频率是多少？
5. 是否存在真值障碍物话题？
6. YAML 中是否有相机内参和畸变参数？
7. 是否可以导出任意一帧点云和图像？

## 8. 风险与应对

| 风险 | 应对方法 |
|---|---|
| MCAP 无法直接读取 | 使用 `ros2 bag play` 回放，或安装 mcap/rosbag2_py 工具 |
| 没有 CameraInfo | 使用 YAML 或根据 FOV 估计初始内参 |
| topic 命名与 PDF 不一致 | 以 MCAP 实际 topic 为准，建立映射表 |
| 真值话题缺失 | 用人工标注少量帧做验证 |
| 时间戳不同步 | 先使用近邻时间同步，后续再做精确同步 |
